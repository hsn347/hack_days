# تقرير فني مستقل مسبق قبل تنفيذ أوامر الفحص والتحقق (Milestone 3 Forensic Audit)

## 1. تشخيص السبب ولماذا هذا الإجراء مطلوب
تطبيقاً للقاعدة رقم 5 في دستور العمل (`GEMINI.md`)، وتكليف المشرف الأعلى للمدقق الجنائي (`auditor_p2_m3`) لفحص مخرجات المرحلة الثالثة (Milestone 3: دورة حياة العمليات الحية، ترقيم الصفحات، وحجز الموارد):
يتطلب الفحص الجنائي التحقق التجريبي الصارم والمستقل مما يلي:
1. فحص سلامة الملفات المحظورة قطيعاً (`game_client.py`، `core/onemt_auth.py`، `core/onemt_bot.py`) والتأكد من عدم لمسها أو تعديلها بواسطة `git status`.
2. تشغيل جناح اختبارات المرحلة الثالثة المستقل `tests/test_live_operations_m3.py` للتحقق من اجتياز 4/4 اختبارات.
3. تشغيل جناح الاختبارات الشامل للمنصة `tests/run_all_tests.py` للتأكد من اجتياز 30/30 اختبار دون أي تراجع (Zero Regression).
4. التحقق من بناء الواجهة الأمامية `npm run build` للتأكد من خلو ملفات TypeScript من أي أخطاء ترجمة.

## 2. المنطق والخطوات التي سيتم تطبيقها
- **الخطوة الأولى**: فحص حالة المستودع لملفات الحظر الثلاثة باستخدام `git status --porcelain` للتأكد بنسبة 100% أنها غير معدلة تماماً.
- **الخطوة الثانية**: تشغيل أمر بايثون المحلي `python tests/test_live_operations_m3.py` للتحقق المباشر من صحة تصنيف الحالات الست، عزل الخيوط العالقة، منع تكرار التشغيل الذري، وترقيم الصفحات.
- **الخطوة الثالثة**: تشغيل أمر بايثون المحلي `python tests/run_all_tests.py` للتأكد من أن كامل المنظومة تعمل بانسجام تام.
- **الخطوة الرابعة**: تشغيل بناء الواجهة الأمامية محلياً عبر `npm run build` في مجلد `dashboard`.

## 3. الملفات والسطور والأوامر التي ستُنفذ بالتفصيل والنتيجة المتوقعة
1. **أمر فحص Git للملفات المحظورة**:
   - الأمر: `git status --porcelain game_client.py core/onemt_auth.py core/onemt_bot.py`
   - النتيجة المتوقعة: مخرجات فارغة تماماً (Exit code: 0)، مما يثبت عدم تعديل أو لمس أي من هذه الملفات.
2. **أمر اختبارات المرحلة الثالثة**:
   - الأمر: `python tests/test_live_operations_m3.py`
   - النتيجة المتوقعة: اجتياز 4 اختبارات بنجاح تام (`Ran 4 tests ... OK`).
3. **أمر الاختبارات الشاملة للمشروع**:
   - الأمر: `python tests/run_all_tests.py`
   - النتيجة المتوقعة: اجتياز كافة الاختبارات الـ 30 بنسبة 100% (`Pass: 100.0%`).
4. **أمر بناء الواجهة**:
   - الأمر: `powershell -Command "Set-Location dashboard; npm run build"`
   - النتيجة المتوقعة: اكتمال البناء بنجاح مع كود خروج 0 (`built in ...`).
