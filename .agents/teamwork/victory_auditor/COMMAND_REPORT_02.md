# تقرير فني مسبق رقم 2: فحص الخط الزمني وسجلات Git للوكلاء

## 1. تشخيص السبب ولماذا هذا الإجراء مطلوب
كجزء من المرحلة الأولى من تدقيق النصر (Phase A: Timeline & Provenance Audit)، يجب التحقق من عدم وجود تزوير زمني أو ملفات سابقة التجهيز، والتأكد من التسلسل المنطقي لعمل الوكلاء الـ 20 عبر فحص تواريخ إنشاء وتعديل مجلدات الوكلاء وملفاتهم وسجل git.

## 2. المنطق والخطوات التي سيتم تطبيقها
- تشغيل أمر git لاستخراج التواريخ والتفاصيل لآخر الالتزامات.
- فحص تواريخ ملفات `handoff.md` و `progress.md` داخل مجلدات الوكلاء (agent1 إلى agent20 ومجلدات العمال).

## 3. الأوامر التي ستُنفذ بالتفصيل والنتيجة المتوقعة
- الأمر: `powershell -NoProfile -Command "Get-ChildItem -Path .agents/teamwork -Recurse -Filter 'handoff.md' | Select-Object FullName, LastWriteTime | Sort-Object LastWriteTime"`
  النتيجة المتوقعة: جدول زمني بترتيب تسليمات الوكلاء يثبت التتابع الحقيقي لعمل الوكلاء الـ 20.
- الأمر: `git log -n 10 --format='%h %cd %s' --date=iso`
  النتيجة المتوقعة: تواريخ الالتزامات في المستودع.
